# LearnLocal 0.2.0

LearnLocal 0.2.0 adds a complete Electronics Engineering curriculum and refreshes the desktop application with a denser editorial design system.

## Highlights

- Added **Electronics Engineering Foundations**, a 46-chapter, 184-lesson offline curriculum with 147 exercises, worked solutions, diagrams, component imagery, laboratories, troubleshooting practice, milestone projects, and a capstone.
- Redesigned the complete application around the Foundation editorial theme system.
- Simplified **My Courses** to one detailed library view.
- Reworked the dashboard so its complete overview fits the default 1440×900 desktop window.
- Replaced ambiguous exercise glyphs with clear labels such as Quiz, Answer, Calculation, Lab, Code, Fix, and Project.
- Applied the LearnLocal logo to the native Windows application, taskbar, installer, and portable executable.
- Expanded the course-authoring documentation with a complete workflow for creating new topics, lessons, exercises, solutions, tests, diagrams, and projects.
- Updated Electron, Vite, Vitest, Zod, and DOMPurify to patched compatible releases.

## Downloads

- `LearnLocal-0.2.0-x64.exe` — Windows installer.
- `LearnLocal-Portable-0.2.0-x64.exe` — self-contained portable application. Its data is stored in `LearnLocal-Data` beside the executable.
- `javaCourse.zip` — Java Developer Academy. Extract it, then import the folder containing `manifest.json`.
- `electronicsCourse.zip` — Electronics Engineering Foundations. Extract it, then import the folder containing `manifest.json`.

The Windows executables are currently unsigned, so Windows SmartScreen may display an unrecognized-publisher warning.
